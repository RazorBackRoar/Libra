# Scope — L!bra design audit

- **What:** Primary macOS SwiftUI surfaces — Home (Video/Photo), ToolPage, Settings, GPS map, category browser. Source + `docs/screenshots/app.png` (Home).
- **Primary user:** macOS Apple Silicon creators/archivists organizing local video libraries.
- **Primary task:** Pick a tool → drop folder/files → preview (Dry Run) → write organize/rename/transform.
- **Constraints:** Brand **L!bra** / machine `Libra`; SwiftUI + AppKit; local-first; yellow-on-black visual language already shipping; no Figma source in repo.
- **Out of scope:** README marketing layout; packaging/DMG chrome; runtime Instruments (Ubuntu agent).
- **References:** Peer file organizers (Hazel-like rules, Name Mangler, Digikam) — not cloned in UI.
